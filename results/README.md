# Results directory

- `logs/main-paper/` contains the archived outputs associated with the main paper experiments.
- `logs/additional/` contains archived analyses and additional experiments.
- `runs/` is the default destination for newly generated experiment logs and is ignored by Git.
- `reconstructions/` is the default destination for newly generated reconstructed images and is ignored by Git.

The archived directories intentionally remain versioned to preserve the original reproducibility record. Do not overwrite them with new runs.
